# Forest

Web quản lý nội dung & cuộc sống: lịch nội dung (sản phẩm / booking), reminder, thói quen, finance, quick note, project, âm thanh thư giãn + pomodoro.

```bash
npm install
npm run dev      # mở http://localhost:5173
npm run build    # build bản tĩnh vào dist/
```

Dữ liệu lưu trong `localStorage` của trình duyệt. Vào **Cài đặt → Xuất JSON** để sao lưu.
Xem kế hoạch chi tiết ở [PLAN.md](PLAN.md).
